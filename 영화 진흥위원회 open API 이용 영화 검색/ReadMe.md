# 🎬 영화진흥위원회 Open API 이용 영화 검색 사이트

KOBIS(영화진흥위원회)에서 제공하는 Open API를 연동하여, 사용자가 지정한 날짜의 일별 박스오피스 순위를 조회하고 각 영화의 상세 정보를 모달(Modal) 창으로 확인할 수 있는 웹 애플리케이션입니다.

- **작성일:** 2026. 06. 16
- **개발 환경:** HTML5, CSS3, Vanilla JavaScript (ECMAScript 6+)

---

## 📁 파일 구성

* **README.md**: 본 프로젝트에 대한 개요 및 소스코드 설명 문서
* **exam05.html**: 오픈 API 연동 및 인터페이스 구현 메인 파일
    * 일자별 박스오피스 순위 출력
    * 영화별 상세 정보 모달창 표출
    * *주의: 영화진흥위원회 API 자체에서 포스터 이미지를 제공하지 않으므로, 추후 TMDB 또는 KMDB API를 활용해 포스터 기능을 추가할 예정입니다.*

## 🔍 코드 설명

### 🎨 CSS 부 (스타일 정의)
* **메인 박스 (`#searchResult`)**: 상단 날짜 조회 후 결과 리스트가 출력되는 영역으로, 빨간색 테두리와 내부 스크롤(`overflow-y: auto`)이 구현되어 있습니다.
* **상세정보 모달 (`.modal`, `.modal-overlay`)**: [상세내용보기] 버튼 클릭 시 화면 중앙에 나타나는 팝업 창과 배경 어두움 처리를 담당합니다.

### ⚙️ JavaScript 부 (기능 구현)

모든 함수와 이벤트 리스너는 문서의 구조가 완전히 로드된 후 안전하게 실행되도록 `DOMContentLoaded` 이벤트 내부에서 동작합니다.

#### 1. 주요 변수 설명
* `searchResult`: 조회된 영화 목록이 동적으로 주입되는 결과 박스 DOM 객체
* `modal`, `overlay`, `closeModal`, `modalBody`: 상세 정보 모달 창을 제어하기 위한 각각의 DOM 객체

#### 2. 핵심 함수 & 이벤트 세부 사항

* **`getDailyBoxOffice(searchDate)`**
    * **역할:** 일별 박스오피스 목록 조회 (비동기 `async/await` 사용)
    * **동작:** 사용자가 선택한 날짜를 `YYYYMMDD` 형식으로 변환 후, API 키와 함께 GET 방식으로 요청을 보내 JSON 결과를 반환받습니다.
* **`searchBtn.addEventListener('click', ...)`**
    * **역할:** 날짜 조회 버튼 클릭 이벤트
    * **동작:** `getDailyBoxOffice` 함수를 호출하여 데이터를 받아온 후, 배열을 순회(`forEach`)하면서 화면에 순위와 영화 제목, 그리고 고유 영화코드가 담긴 버튼을 생성합니다.
* **`getMovieDetail(movieCode)`**
    * **역할:** 영화 상세 정보 데이터 요청
    * **동작:** 박스오피스 결과에서 추출한 영화 고유 코드(`movieCd`)를 파라미터로 받아 KOBIS 상세정보 API로 조회 요청을 보냅니다.
* **`searchResult.addEventListener('click', ...)`**
    * **역할:** [상세내용보기] 버튼 클릭 이벤트 (이벤트 위임 방식 적용)
    * **동작:** 동적으로 생성된 버튼이 클릭되면 해당 영화 코드를 식별하여 `getMovieDetail` 함수를 실행하고, 반환받은 감독·장르·관람등급 등의 데이터를 모달창 내부에 채워 화면에 표시합니다.
* **`closeModal`, `overlay` 이벤트 리스너**
    * **역할:** 닫기(`X`) 버튼 혹은 모달창 바깥의 어두운 배경을 클릭했을 때 팝업을 닫아주는 토글 기능을 수행합니다.

### 🌐 HTML 부 (구조 정의)

| ID / Class 명 | 태그 종류 | 역할 설명 |
| :--- | :--- | :--- |
| `#searchDate` | `<input type="date">` | 조회를 원하는 날짜를 선택하는 캘린더 인터페이스 |

| `#modalBody`   | `<div>` | 영화명, 감독, 개봉일 등 텍스트 콘텐츠가 주입되는 영역 |
